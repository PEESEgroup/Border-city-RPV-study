# Supplementary economic-uncertainty figure Source Data

The table contains the median, 2.5th-percentile and 97.5th-percentile propagated scenario summaries plotted in the Supplementary economic-uncertainty figure. The 12 primary cities each have 1,000 Monte Carlo draws. These ranges propagate the stated input perturbations and are not confidence intervals or observed project distributions. Detroit and Windsor are not included in this standardized primary-city figure.
